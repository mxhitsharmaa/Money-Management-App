# Money Management System

A web-based Money Management System built with PHP and MySQL to help users manage their personal finances, track income and expenses, and organize financial transactions through a simple interface.

## Features

- User authentication using JWT
- Income and expense tracking
- Add, view, update, and delete transactions
- Transaction category management
- Financial transaction history
- User profile management
- Password change functionality
- REST API-based backend
- MySQL database integration

## Technologies Used

- PHP
- MySQL
- JavaScript
- JSON Web Tokens (JWT)
- REST API

## Project Structure

```text
Money-Management-App/
├── api/          # API endpoints
├── config/       # Database and application configuration
├── index.php     # Application entry point
└── README.md
```

## Installation

1. Install XAMPP and start Apache and MySQL.
2. Clone this repository into your XAMPP `htdocs` directory.
3. Create a MySQL database using phpMyAdmin.
4. Import the required database tables and structure.
5. Configure the database connection in the configuration files.
6. Open the project in your browser:

   `http://localhost/Money-Management-App/`

## Security

- JWT-based authentication
- Protected API endpoints
- Server-side input validation
- Database queries using appropriate safeguards

## Purpose

This project demonstrates practical PHP development, database management, REST API integration, authentication, and CRUD operations for personal finance management.
